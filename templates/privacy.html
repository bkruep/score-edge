PRIVACY POLICY

LAST UPDATED: OCTOBER 2026

{% endblock %} {% block content %}

This policy explains what information ScoreEdge ("the site", "we") handles when you use it, and the third parties involved. It is written plainly; where we are not certain which category a piece of data falls into, we treat it conservatively.

Information we handle

  • Nothing you type is stored on a server except optional API keys you explicitly save for the golf and horse-racing tools. Those keys are written to the app's own local settings file and are used only to call the matching provider on your behalf.
  • Tool state that is meant to survive a reload — for example a saved bankroll value or a watchlist — is stored locally or on the app instance serving you, not shared with advertisers.
  • Like most web hosts, the infrastructure provider may log standard request data (IP address, user agent, timestamp) for security and uptime. We do not sell this data.

Third-party data providers

The site displays odds, stats and model numbers supplied by external providers (including sportsbook odds aggregators, DataGolf, FormFav and the NHL/MLB public stats APIs). When you use a tool that calls one of those providers with your own API key, your request goes to that provider under their terms and privacy policy. We do not control their practices.

Cookies & analytics

The site does not run third-party advertising trackers. Any local storage is used only to make the tools work.

Children

The site is intended for adults of legal wagering age. It is not directed at children.

Your choices

You can clear any locally saved preference by clearing your browser storage, and you can remove a saved API key by saving an empty value in the relevant tool. To request changes or ask a question, see the contact page.

Changes

This policy may be updated as the site changes. Continued use after an update means you accept the revised policy.
